# Getting started

> Placeholder para onboarding de novos developers.

## Checklist

1. Clonar o repositório
2. Instalar MongoDB localmente (ou apontar `MONGO_URL`)
3. Configurar `backend/.env` a partir de `.env.example`
4. Configurar `frontend/.env` a partir de `.env.example`
5. Arrancar backend e frontend (ver README raiz)
6. Entrar com o utilizador admin definido no `.env`

## Problemas comuns

- [ ] CORS — verificar `CORS_ORIGINS`
- [ ] MongoDB não acessível — verificar `MONGO_URL`
- [ ] Frontend sem API — verificar `REACT_APP_BACKEND_URL`
